## 12조 스펙트라 면접 브리핑

NaCl 농도에 따른 mCP 흡수 스펙트럼 연구를 설명하기 위한 정적 HTML 자료입니다.

- `index.html`: Canva 브리핑 임베드
- `spectrum.html`: 농도별 흡수 스펙트럼
- `calibration.html`: 흡광도비 검량선
- `unknown.html`: 미지 시료 농도 예측
- `controls.html`: 통제변인 비교
- `errors.html`: 측정 오차 비교
- `workflow.html`: 전체 실험 과정

시뮬레이션의 수치는 설명용 가상 데이터이며 실제 예상 결과가 아닙니다.
