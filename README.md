## 12조 스펙트라 면접 브리핑

NaCl 농도에 따른 mCP 흡수 스펙트럼 연구를 위한 10쪽 HTML 발표 자료입니다.

- `index.html`부터 시작합니다.
- 각 발표 슬라이드는 독립된 HTML 파일입니다.
- `Space`, `←`, `→`, `PageUp`, `PageDown`으로 이동할 수 있습니다.
- 스펙트럼·통제변인·검량선·측정오차 시뮬레이션이 관련 슬라이드에 포함되어 있습니다.
- 공통 스타일은 `css/`, 공통 동작은 `js/` 폴더에 있습니다.

시뮬레이션 수치는 설명용 가상 데이터이며 실제 예상 결과가 아닙니다.
